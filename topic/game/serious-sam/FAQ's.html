"How do I install Super Project?"

~~~ Download the latest release of the mod via the "Releases" section on Github (https://github.com/SamClassicPatch/SuperProject/releases/tag/1.9.4),
click either "The First Encounter" or "The Second Encounter" if you have Serious Sam: The First Encounter or Serious Sam: The Second Encounter,
extract the mod's file, then go to your Serious Sam file directory and drag all the files in the mod folder into your Serious Sam directory.


DISCLAIMER: The patch will be under the "Mods" section in Serious Sam! Look in that menu and click on it, so you can actually play the patch!
